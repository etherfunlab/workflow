# writing

出自心法：菜就多练。这是人给 agent 立的尺子：agent 写文档时照着写，人审稿时拿它量。

## 这是什么

一套写作规范和用词规范，管所有写给人读的 Markdown：README、设计文档、开发日志、release notes。装进你的仓以后，agent 每次读写 `.md` 文件都会载入它。

## 为什么

模型写的文字有一组固定的痕迹：不指向任何东西的抬价词，拿「东西」「那一套」顶替概念的代指词，「值得注意的是」这类只报结构、不报关系的路标，还有先凭空立一个靶子再推倒的对比句。读者认出这些痕迹，就开始跳读。规范把它们列成判据，agent 起草时就能避开，人审稿时也有据可查。

## 规矩

- **平实指动词，名词要准。** 句子短，用主动语态，不含糊其辞。名词要准到换不掉，有术语就用术语（幂等、同构、收敛）。协议名和缩写保持原样，不翻译。
- **删除清单按判据用。** 清单分四类：抬价词、代指词、比喻性的身体动作动词（走、打、跑、落）、路标。同一个词在这一句是术语，到下一句可能就是违规，所以只能逐句读、逐句判，不能搜索替换。
- **相邻两句有逻辑关系，就写出连接词。** 用但是、因此、那么、虽然点明关系。连接词必须为真；没有关系就不写，列表就该长得像列表。
- **对比句式默认禁止。** 「不是 A，是 B」这类句子，只有说得出 A 的出处才能写：审阅意见、旧版文档、另一篇文档的结论、真实数据造成的错觉。说不出出处，A 就是作者自己立的靶，删掉。引文照原样保留，原话里的对比句也不改。这条在起草和终审两处把关，润色阶段只标记、不改写。
- **不灌水。** 写结果，不写口号。未来的计划可以写，标明是计划。
- **中文排版。** 中文旁边用全角逗号「，」，不用半角 `,`。不用 en-dash（U+2013），数字范围写 ASCII 连字符 `-`。中文破折号「——」可以用。

完整规则在 [`agent/rules/writing.md`](agent/rules/writing.md)。

## 篇级宪法

句级规则之外，模块还带一份 `WRITING.md` 装到仓根，管整篇：动笔前的三问定位、一篇只归一个读者、技术复盘的结构、byline 写实际分工、各文体的边界、反 AI 腔的结构层（为什么禁用词表拦不住、哪些句法框架在填空位，完整论证见 [blog 这篇](https://blog.etherfun.xyz/zh/posts/2026-09-02-word-blacklists-dont-stop-ai-prose)），以及最关键的一条：**哪一道工序拦哪一层**——判一条规则要的事实在句子外面时，只能起草拦；润色手上只有句子，见到只标不改、退回起草。

## 装进你仓里的是什么

- Claude Code：`.claude/rules/writing.md`，带 `paths: ["**/*.md"]`，只在读写 Markdown 时载入。
- 其他 agent：AGENTS.md 里的一节「When editing `**/*.md`」。
- 两者通用：仓根 `WRITING.md`，成篇写作前读。

## 依赖

润色用两个第三方 skill。本仓不收它们的本体：ADOPT 会给出上游链接和安装命令，你点头才装。

- 中文稿：[human-writing](https://github.com/Tao716/human-writing-skill)
- 英文稿：[humanizer](https://github.com/blader/humanizer)

技术文档里有两条以本仓规则为准，优先于 human-writing 自带的禁令：

| human-writing 的规定 | 技术文档里 |
|---|---|
| 禁用破折号 | 中文破折号「——」保留 |
| 禁用冒号 | 冒号照用；表格、命令、路径、代码块原样不动 |

代码、命令、路径、表格、英文术语和并列条目按保守模式处理，不为了句式错落去改。
