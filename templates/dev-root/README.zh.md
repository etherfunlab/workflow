# dev-root

出自心法：权威唯一。跨仓的姿态写在上层文件里，一个仓自己的规则留在那个仓。

## 这是什么

一份装在「各个 repo 上一层目录」的 CLAUDE.md 模板：prod 数据通道、报告数字的窗口与 era、公开仓纪律、PR 节奏、花钱 API、观感判官、先查后问、提交卫生。Claude Code 会把上层目录的 CLAUDE.md 自动载入到下面每个仓的会话里，这些规则写一份就对全部仓生效。

## 为什么

这些规则一仓抄一份，迟早有一份改漏。上层目录只存一份，就是「权威唯一」用在规则文件上。上层目录通常不是 git 仓，历史靠 hook 把它镜像进一个 git 仓，镜像永远不手改。

## 装进你仓里的是什么

- `CLAUDE.md`，装到目标仓的上一层目录（不进仓里），空位写 `TODO:`，由你填。
- **仅 Claude Code**：其他 agent 不读上层目录。用别的 agent 的话，把你要的条目并进各仓的 AGENTS.md。

## 依赖

无。镜像历史可以拿 rules-files 模块的 `mirror-rules-backup.example.sh` 改一份。
